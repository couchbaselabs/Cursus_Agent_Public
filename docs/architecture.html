App layer — apps/
🖥 NiceGUI apps/nicegui/app.py
  • Full desktop-class web UI
  • Scraping tab — pipeline controls + job monitor
  • Results, Customers, Analytics, Assets tabs
  • Chat tab — agent loop with tool status strip
  • Scoring / RAG / FTS query panel
  • Charts: 12 types, 6 palettes, SVG/PNG export
  • Quick Dashboard: 6 CB metric charts
  • run via run_nicegui.py
💬 Chainlit apps/chainlit/app.py
  • Mobile-friendly chat-first interface
  • Settings panel: customer + LLM provider
  • Live tool status per agent turn
  • Follow-up suggestion chips
  • Retry on error, asset restore on resume
  • Session persistence via CB data layer
  • Job monitors survive tab close + reconnect
  • run via run_chainlit.py
🔌 MCP Server apps/mcp/server.py
  • All 29+ agent tools exposed via MCP stdio
  • Claude Desktop config supported
  • Auth: CB credentials via env vars
  • Tool result streaming for long-running ops
  • README: Claude Desktop setup + examples
